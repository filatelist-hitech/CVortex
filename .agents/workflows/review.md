# Review Workflow

## Scope

Review changes for correctness, security, architecture alignment and documentation completeness.

## Review Order

1. Phase/scope compliance.
2. Truth-first compliance.
3. Security and authorization.
4. Correctness.
5. Architecture/ADR consistency.
6. Tests and validation.
7. Error handling.
8. Documentation.
9. Backward compatibility.
10. State updates.

## Output

Record:

- findings;
- severity;
- affected files;
- required corrections;
- validation status.

Do not approve work that claims tests or validation that were not actually performed.
