# CVortex

**Поиск работы на основе проверенного опыта, а не фантазий нейросети.**

CVortex помогает находить вакансии и готовить отклики, опираясь только на подтверждённые факты вашей биографии. Система сопоставляет реальный опыт с требованиями работодателя, а любое утверждение в готовом письме или резюме всегда связано с первоисточником.

## Где мы сейчас

В коде готовы этапы M1.1, M1.2 и M1.3, а срез M1.4 собран в ветке `stage`. Проект находится на фазе Preview 0.1: собираем обратную связь и проверяем сценарии на реальных данных. К разработке M2 ещё не приступали.

## Что уже работает

- Вход по приглашениям и изолированные профили пользователей.
- Ручное добавление карьерных фактов без нейросетей. Если вставить текст резюме или заметок, система сама предложит факты, но в базу они попадут только после вашего личного подтверждения.
- Разбор вакансий из текста: CVortex находит ключевые требования, сверяет их с подтверждённым опытом по 7 направлениям и аргументированно подсказывает приоритет отклика.
- Подготовка отклика: точечные советы по резюме и два варианта сопроводительного письма (краткий и подробный). Черновики можно править, принимать или отклонять. Финальное утверждение доступно только для версий, успешно прошедших проверку достоверности (Truth Guard).

Для автоматического извлечения фактов и генерации черновиков требуется LLM-провайдер. По умолчанию он выключен (`AI_PROVIDER=none`). Ссылка на вакансию сохраняется исключительно как текстовая заметка: приложение не переходит по ней и не скачивает веб-страницы.

## Как устроен рабочий процесс

```mermaid
flowchart LR
  Invite[Получить инвайт и войти] --> Facts[Подтвердить факты карьеры]
  Facts --> Vacancy[Вставить текст вакансии]
  Vacancy --> Match[Оценить совпадения и пробелы]
  Match --> Drafts[Сгенерировать и отредактировать черновики]
  Drafts --> Guard[Пройти Truth Guard]
  Guard --> Approval[Утвердить финальный текст]
  Approval --> Stop([Остановиться до отправки])
```

Подробная [карта процессов](docs/00-Home/Process-Map.md) описывает движение данных, правила локального запуска и диагностику сбоев.

## Быстрый старт

Потребуются Git, Make, Docker с Compose и запущенный Docker daemon.

```sh
git clone https://github.com/filatelist-hitech/CVortex.git
cd CVortex
make init
docker compose --env-file .env config --quiet
make up
make migrate
health_authority="$(docker compose port nginx 80)"
curl -fsS "http://${health_authority}/api/v1/health/ready"
```

После успешного ответа готовности откройте в браузере адрес `APP_URL` из файла `.env` (по умолчанию `http://127.0.0.1:8080`).

Подробное руководство по настройке и решению проблем читайте в [инструкции по локальной установке](docs/10-Operations/Local-Development.md). Создание первого администратора и генерация приглашений описаны в [руководстве по управлению доступом](docs/10-Operations/M1-Access-Core.md).

## Текущие ограничения

CVortex пока не экспортирует файлы DOCX/PDF и не умеет автоматически отправлять отклики работодателям. Шлюз MCP по умолчанию выключен: при явной активации он работает только на чтение контекста. Помните, что карьерные факты и тексты вакансий содержат персональные данные — не коммитьте их в Git вместе с секретами окружения.

## Интеграция с локальным ChatGPT

В [инструкции по ChatGPT Plan Chat](docs/10-Operations/ChatGPT-Plan-Chat.md) описан альтернативный путь без API-ключей через подписку ChatGPT (Sign in with ChatGPT): со стримингом ответов, историей диалога и сохранением черновиков анализа. Архитектура шлюза зафиксирована в [документе MCP Gateway](docs/02-Architecture/MCP-Gateway.md). MCP здесь работает как адаптер данных, а не вычислительный бэкенд. Стандартный режим работы через API-ключи OpenAI по-прежнему поддерживается.
