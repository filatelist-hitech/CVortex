# Vision

## Product vision

CVortex should become a personal operating system for the complete job-search loop: understanding a vacancy, deciding whether to apply, preparing truthful application materials, preserving employer-specific context, supporting interviews, and learning from outcomes.

The product exists because job-search work is fragmented across resume files, vacancy pages, chat histories, recruiter messages, notes, spreadsheets, and one-off AI conversations. That fragmentation creates repeated work and, more dangerously, inconsistencies in how the same candidate describes the same experience.

CVortex keeps the context together.

## User value

The system should make each application:

- **truthful** — no invented skills, projects, responsibilities, seniority, or experience;
- **relevant** — emphasize confirmed facts that matter for the specific vacancy;
- **consistent** — remember what has already been communicated to the same employer;
- **traceable** — preserve provenance from generated wording back to source facts;
- **reviewable** — show recommendations and important changes before they become part of an application package;
- **efficient** — reuse structured context instead of rebuilding it in every AI chat;
- **evidence-aware** — base market and hiring recommendations on versioned research rather than folklore.

## Primary workflow

```text
Vacancy
  ↓
Normalize and extract requirements
  ↓
Match against confirmed Career Facts
  ↓
Should I apply?
  ↓
Resume recommendations
  ↓
Truth and consistency checks
  ↓
User approval
  ↓
Resume + cover letter package
  ↓
Manual application
  ↓
Conversation + interview context
  ↓
Outcome + analytics
```

## Product identity

- **Name:** CVortex
- **Primary tagline:** *Your career, in context.*
- **Design direction:** dark-first, deep navy/black base with cyan/blue/violet accents and Space Grotesk typography.
- **Visual source of truth:** Figma.

## What success looks like

CVortex succeeds when the user can return after many applications and still answer, with evidence:

- which facts were used for a specific vacancy;
- what exact resume and cover letter were prepared or sent;
- what was already told to a specific employer;
- whether a new statement contradicts prior employer context;
- why the system recommended applying or skipping;
- which job-search strategies are producing useful outcomes.
