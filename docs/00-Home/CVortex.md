# CVortex

**Поиск работы на основе проверенного опыта, а не фантазий нейросети.**

[Сводка состояния проекта и текущая задача](CURRENT-PROJECT-STATE.md) (актуальное состояние хранится в `.agents/state/`).

CVortex помогает искать вакансии и собирать материалы отклика, опираясь исключительно на подтверждённые факты вашей профессиональной биографии.

## Что доступно сейчас

В локальной версии Preview 0.1 можно зарегистрироваться по инвайту, внести карьерные факты вручную или автоматически вычленить их из текста резюме. Приложение умеет анализировать текст вакансий, оценивать совпадения по 7 ключевым параметрам и генерировать черновики сопроводительных писем и советов по резюме. Любой сгенерированный текст проходит строгую проверку Truth Guard на отсутствие выдуманных фактов.

Для работы автоизвлечения и генерации требуется подключённый LLM-провайдер (в дефолтной установке он отключён, `AI_PROVIDER=none`). Ссылка на вакансию сохраняется для справки: страницы по ссылкам система не скачивает.

Функционал M1.4 уже находится в ветке `stage`. Проект проходит фазу пользовательского тестирования Preview 0.1, этап M2 пока не стартовал. Генерация файлов DOCX/PDF, история переписки с компаниями и автоматическая отправка откликов пока не реализованы.

Осваивать систему лучше всего с [[User-Guide|руководства пользователя]]. Инженерам и администраторам пригодятся [[../10-Operations/Local-Development|инструкция по локальной установке]] и [[../10-Operations/M1-Access-Core|руководство по управлению доступом]]. Общая структура файлов собрана в [[Documentation-Map|карте документации]].

## Базовые принципы

- Никаких выдумок: каждое утверждение в отклике опирается на подтверждённый факт карьеры.
- Человек в центре: факты, предложенные алгоритмами, остаются неподтверждёнными до вашей проверки.
- Безопасность данных: текст вакансий, входящие сообщения и документы считаются недоверенным вводом.
- Контроль за вами: CVortex не отправляет отклики и не связывается с работодателями без вашего явного участия.
