## Подтверждённая первопричина

В чистой ветке stage воспроизводится ошибка `manifest source/hash drift`. Независимый расчет хэшей Git blob, рабочей копии и свежезагруженного исходного внешнего файла подтверждает:

| Представление файла | Размер в байтах | Переводы строк CRLF | SHA-256 |
| --- | ---: | ---: | --- |
| Исходный внешний файл | 4495 | 93 | `564ce565c371c5e5bbf286006565a7c9aa55a9f56e7ca58d56e05d649dd61a72` |
| Внешний файл после конвертации Git в LF | 4402 | 0 | `c6dec685825f73b18c20926fddc65e8315642e12986f15db0699170940a09efc` |
| Файл OFL в репозитории / рабочая копия / текущий манифест | 4401 | 0 | `18a4de52385f6b988782639d5d0cc1326e5a8c2de9a7f01d7b20d9aedcc60943` |

В корневом файле `.gitattributes` задано правило `text=auto eol=lf`; команда `git ls-files --eol` возвращает `i/lf w/lf`. Специфических фильтров clean/smudge не настроено. Стандартная очистка Git заменяет CRLF на LF, но **не удаляет** пробелы в конце строк. Один концевой пробел после фразы `bundled, embedded,` был удален отдельно в истории коммитов. Весь остальной текст лицензии совпадает посимвольно при стандартной нормализации пробельных символов. В старом манифесте в поле для проверки локального файла репозитория ошибочно был записан хэш внешнего файла.

См. [отчёт о проверке происхождения](evidence/qa-001-2026-10-12/provenance-verification.json). [Исходный внешний файл лицензии](https://raw.githubusercontent.com/floriankarsten/space-grotesk/03507d024a01282884232081fc6011c09ff4e849/OFL.txt) был повторно скачан 12.10.2026 г.; для офлайн-проверок используется [фикстура в base64](evidence/qa-001-2026-10-12/upstream-ofl.json).

## Выбор политики нормализации байтов

| Вариант | Последствия | Решение |
| --- | --- | --- |
| A: хранение нормализованного LF + отдельный хэш внешнего источника | Сохраняет текущий файл OFL и корневые правила Git; хэши внешнего источника и локального файла имеют раздельный явный смысл | Выбрано |
| B: хранение точных байтов внешнего файла + точечное исключение в Git | Потребовало бы вернуть CRLF и концевой пробел, изменив файл в репозитории и добавив исключение | Контрактом не требуется |

Политика A определена как `lf-trim-trailing-horizontal-whitespace`: замена CRLF на LF и удаление только концевых пробелов и табов в конце строк. Текст лицензии не изменился. Условия, права использования, шрифты, дизайн-токены и визуальный эталон остались без изменений.

Поля `sha256` и `bytes` в файле `font-source.json` сохраняют смысл для **внешнего источника**; новый блок метаданных `stored` описывает дайджест, длину и фикстуру для файла в репозитории. Скрипт проверки валидирует декодированную фикстуру, хэш, длину, точную нормализацию и сохранённые байты **перед выполнением как проверки, так и записи**. Хранение в base64 позволяет передавать исходный файл с CRLF через Git без добавления исключений в `.gitattributes` и без сетевых запросов во время тестов.

Поле `manifest.generated.referenceAssetSha256` по-прежнему хэширует реальные файлы ассетов. В манифесте обновлены только 4 хэша: `assets/OFL.txt`, `assets/font-source.json`, `build-reference.cjs`, `build-reference.test.cjs`. Все остальные поля манифеста, токены и стили `tokens.css` остались без изменений. [Снимок хэшей до исправления](evidence/qa-001-2026-10-12/baseline.json) служит опорой для проверки отсутствия регресса.
