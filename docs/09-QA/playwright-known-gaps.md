# CVortex Playwright Known Gaps & Unimplemented Features

## 1. Честная фиксация ограничений

В соответствии с правилами CVortex и контрактом задачи, мы не изобретаем отсутствующую функциональность и не создаём фиктивные тесты под незавершённые функции.

Ниже зафиксированы все выявленные пробелы между спецификацией продукта и текущим состоянием кодовой базы.

## 2. Не реализованные в UI функции (Documented / Not Implemented)

### 2.1 Импорт вакансий через файлы (DOCX / PDF)
- **Спецификация**: раздел 16.3 задачи предполагает загрузку документов резюме и описаний вакансий.
- **Фактическое состояние**: в UI реализована только форма вставки текста (`raw_text`). Файловый дроппер и парсер файлов в интерфейсе отсутствуют.
- **Статус**: Documented / Not Implemented (запланировано на M2).

### 2.2 Скрейпинг вакансий по URL
- **Спецификация**: раздел 16.2 предполагает импорт по прямой ссылке с HeadHunter/LinkedIn.
- **Фактическое состояние**: в UI и API парсер внешних страниц не подключён.
- **Статус**: Documented / Not Implemented (M2).

### 2.3 Управление карьерными треками (Career Tracks)
- **Спецификация**: раздел 15 описывает создание и переключение Career Tracks.
- **Фактическое состояние**: интерфейс треков не реализован. Карьерная база фактов является единой.
- **Статус**: Documented / Not Implemented (M2).

### 2.4 Экран настроек и управление API-ключами (BYOK)
- **Спецификация**: раздел 24 описывает настройку провайдеров и маскирование API-ключей.
- **Фактическое состояние**: пункт меню «Настройки» выдаёт сообщение `Экран настроек пока недоступен. Настройки приложения не меняются.`
- **Статус**: Documented / Not Implemented (M2).

### 2.5 Подготовка к интервью (Interview Prep)
- **Спецификация**: раздел 23 описывает генерацию вопросов и подготовку ответов.
- **Фактическое состояние**: страницы и компонентов в Next.js нет.
- **Статус**: Documented / Not Implemented (M3).

### 2.6 Скачивание сгенерированных резюме (DOCX / PDF)
- **Спецификация**: раздел 20.4 описывает выгрузку DOCX/PDF документов.
- **Фактическое состояние**: бэкенд LibreOffice-генерации существует, но в текущем UI кнопка прямого скачивания файла не выведена.
- **Статус**: Documented / Not Implemented (M2).

## 3. Частично реализованные функции (Partially Implemented)

### 3.1 Память работодателя (Employer Memory)
- **Фактическое состояние**: вкладка «Работодатель» присутствует в рабочем пространстве конкретной вакансии, но отдельный раздел `/employers` в меню помечен как «Недоступно».
- **Статус**: Partially Implemented.

## 4. Оставшиеся открытые ворота релиза (Open Release Gates)

- **Manual Accessibility Release Gate (B01)**: ручное тестирование со скринридерами (VoiceOver/NVDA) и нативное масштабирование браузера до 200% остаются обязательными шагами перед релизом и не подменяются автоматическими сканами axe-core.
- **Preview 0.1 Real-User Acceptance**: приёмка реальными пользователями с живыми провайдерами остаётся открытой.
